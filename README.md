# 🚀 Daily Task Manager with Credits & History

Uma aplicação React de alta performance para gerenciamento de produtividade diária, com sistema de gamificação por créditos e histórico persistente.

## ✨ Funcionalidades

- **Gerenciamento de Tarefas:** Adicione, conclua e exclua tarefas com animações fluidas.
- **Reset Diário Inteligente:** Sistema baseado no fuso horário `America/Sao_Paulo`. Ao mudar o dia, o progresso é convertido em créditos e salvo no histórico.
- **Sistema de Créditos:** Ganhe 10 créditos por tarefa e um bônus de 100 créditos ao atingir 100% de conclusão.
- **Histórico:** Acompanhe seu desempenho nos últimos 30 dias.
- **UX Premium:** Dark mode, micro-animações de 60fps (Framer Motion) e feedback visual instantâneo.
- **Performance:** Estado global otimizado com Zustand e componentes memoizados.

## 🛠️ Stack Tecnológica

- **React + Vite** (Fast Refresh e Builds rápidos)
- **Zustand** (Estado global leve com persistência)
- **TailwindCSS** (Estilização utilitária e responsiva)
- **Framer Motion** (Animações complexas e fluidas)
- **Lucide React** (Ícones modernos)

## 📦 Como rodar o projeto

1. Certifique-se de ter o Node.js instalado.
2. No diretório raiz, instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Para gerar o build de produção:
   ```bash
   npm run build
   ```

## 🚀 Deploy

O projeto já está configurado para deploy no GitHub Pages:
```bash
npm run deploy
```
